# 能量库存 · Energy Inventory

> 先录你有的 → 算 30 项营养素覆盖 → 在 2000 kcal 内给出最便宜的补法。

普通饮食 App 只算热量。这个工具解决的是另一个问题：**你手头现有的东西，够不够支撑"高精力"那一天？缺的部分，用最少的钱补哪一样？**

## 快速开始

无需安装、无需构建、无需后端：

```bash
git clone <your-repo> && cd energy-diet
# 直接双击 index.html，或
python -m http.server 8000   # 然后访问 http://localhost:8000
```

> 用 `file://` 直接打开也可以，但部分浏览器会对跨域请求更严格；建议用本地静态服务器。

首次打开会要求你先录入手头**有哪些**食材（不记重量，有就算有；补剂要写清每片含什么）。库存为空时，「今日分析」和「三天食谱」两个页签是锁定的。

## 它做什么

1. **库存录入**：只记「有 / 没有」，不记重量。某样东西吃完了，删掉它，食谱自动重排。补剂单独按「每 1 片/粒」录入成分。
2. **每日配餐**：只用你的库存，按 蛋白 → 乳品 → 蔬菜 → 水果 → 主食 → 油脂 → 补剂 的顺序生成一天食谱，硬裁到 2000 kcal 以内。
3. **覆盖分析**：30 项营养素逐项对比目标，三档着色（达标/接近/不足）。
4. **最便宜补法**：对每个缺口，按「需要几份 × 单价」排序，给出最省的品类与金额。
5. **三天食谱**：同一库存轮换食材生成 3 天计划，汇总日均缺口与采购清单。
6. **精力评分**：睡眠 / 光照 / 咖啡因 / 早餐蛋白 / 含糖饮料 / 久坐打断 / 饮水 / 动机，九项自评 0–100，并给出「今天最该改的三件事」。
7. **数据导入导出**：完整 JSON，可提交进仓库当个人饮食档案。

## 数据来源

不预置食物数据库，全部实时查询 + 本地缓存：

| 源 | 是否要 key | 适用 |
|---|---|---|
| [Open Food Facts](https://world.openfoodfacts.org) | 否 | 带条码的包装食品（中国零食/饮料/蛋白粉覆盖较好） |
| [USDA FoodData Central](https://fdc.nal.usda.gov/api-key-signup.html) | 免费注册，可用 `DEMO_KEY` 试用 | 生鲜食材（米/肉/蛋/菜），英文查询 |
| AI 兜底（OpenAI 兼容接口） | 自备 | 前两者查不到时估算，**数值置信度低**，会标注 |

> 生鲜用英文查命中率高得多：`chicken breast`、`white rice`、`egg`、`broccoli`。
> Open Food Facts 的矿物质字段单位是 g/100g，代码里已统一换算为 mg / μg。

**已知限制**：免费源对中式家常菜的覆盖率不高。长期方向是让社区提交 CSV 或接入中国食物成分表（需授权），而不是靠 LLM 编数字。

## 部署到 GitHub Pages

推送后进入仓库 **Settings → Pages**，Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`，保存。一分钟内即可通过 `https://<用户名>.github.io/energy-diet/` 访问。

## 营养素清单（30 项）

宏量：热量、蛋白质、碳水、脂肪、纤维
矿物质：钙、铁、锌、镁、钾、钠、硒、碘、铜、锰、磷
维生素：A、D、E、K、B1、B2、B3、B6、B9（叶酸）、B12、C
其他：胆碱、Omega-3（EPA+DHA）、ALA

默认目标参照中国居民膳食营养素参考摄入量（18–49 岁男性）+ 减脂期调整，全部可在「设置」里改。安全上限 UL 同样可改，超限标红。

## 配餐算法

不是求解器，是一套可解释的启发式：

```
蛋白 4×150g → 乳品 300g → 蔬菜 3×160g → 水果 2×130g
→ 主食填到 1920 kcal → 油脂补到脂肪 55g → 补剂按缺口补
→ 超过 2000 kcal 时反向削减非蛋白食材
```

优点是每一步都能在界面上看到，缺点是解不唯一、不保证全局最优。想要严格最优，下一步可以接 [diet problem](https://en.wikipedia.org/wiki/Diet_problem) 的线性规划（如 `javascript-lp-solver`）。

## 数据结构

```jsonc
{
  "items": [{
    "id": "abc123",
    "name": "鸡胸肉",
    "brand": "",
    "unit": "g",        // g / ml / 个 / 片 / 粒 / 勺 / 份
    "base": "g",        // g = 每100g；unit = 每1单位
    "per": { "kcal": 133, "prot": 19.4, "ca": 3, "...": 0 },
    "src": "USDA"
  }],
  "targets": { "kcal": 2000, "prot": 130, "...": 0 },
  "ul": { "vd": 50, "...": 0 },
  "cfg": { "usda": "DEMO_KEY" },
  "cache": { "off::chicken breast": [] }
}
```
